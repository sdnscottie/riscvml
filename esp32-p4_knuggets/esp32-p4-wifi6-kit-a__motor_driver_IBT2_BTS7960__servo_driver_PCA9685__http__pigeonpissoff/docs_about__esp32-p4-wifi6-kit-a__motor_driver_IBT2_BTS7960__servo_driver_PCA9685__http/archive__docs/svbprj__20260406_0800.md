# esp32-p4-wifi6-kit-a__motor_driver_IBT2_BTS7960__servo_driver_PCA9685__http

**Author:** Scottie von Bruchhausen (scottie@riscvml.org)
**Board:** Waveshare ESP32-P4-WIFI6 Kit A
**Module:** IBT-2 BTS7960 + PCA9685 + ESP32-C6 Wi-Fi
**Status:** TODO -- combines motor, servo, and WiFi captive portal SvBlocks
**Anki-Ref:** TBD

## Overview

Combined SvBlock: Motor driver + Servo driver + HTTP WiFi captive portal.
This stacks the individual SvBlocks together into one integrated firmware.

Control motors and servos via a web browser over WiFi.

## Prerequisite SvBlocks

| SvBlock | Status |
|---------|--------|
| Flash C6 | WORKING |
| Simple WiFi Connect | WORKING |
| WAP Streamer HTTP (captive portal) | WORKING |
| Motor Driver IBT2 BTS7960 | WORKING (GPIO 25/32/22) |
| Servo Driver PCA9685 | TODO |

## Features (Planned)

- WiFi AP with captive portal (from WAP Streamer HTTP SvBlock)
- Motor speed control via /api/motor (from Motor Driver SvBlock)
- Servo pan/tilt via /api/servo (from Servo Driver SvBlock)
- Combined SPA with motor sliders + servo controls
- NVS WiFi credential storage + Factory Reset
- ESP-IDF v5.4.1
